# Código de conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: seja respeitoso, acolha quem está começando, critique ideias e não
pessoas. Assédio, ataques pessoais e linguagem discriminatória não são
tolerados em issues, pull requests ou qualquer outro espaço do projeto.

Para relatar um comportamento inadequado, use o reporte privado em
**Security → Report a vulnerability** ou entre em contato com o mantenedor
pelo GitHub ([@lucascodebr20](https://github.com/lucascodebr20)). Os relatos
são tratados com sigilo.
